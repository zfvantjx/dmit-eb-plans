## EB 的回程线路：9929、CMIN2、CMI 分别是谁的网

先把几个 AS 号对上人。

**AS4809** 是中国电信的 CN2，GIA 是 CN2 里等级最高的产品，Pro 系列卖的就是这条。**AS9929** 是中国联通的精品网，圈内常说的"9929"就是它，容量比 CN2 GIA 小，但对联通用户来说是最短的一条路。**AS58807** 是中国移动的 CMIN2，移动在国际互联上投入较大的一条线，定位对标 CN2 GIA。**AS58453** 是中国移动国际的 CMI，覆盖面广，东京、香港机房常用它做统一回程。

回程指的是数据从服务器回到你电脑这一段。打开网页、拉文件、看视频，绝大部分流量都走这个方向，所以回程线路对体感的影响比去程大得多。DMIT 东京 EB 的做法是去程电信联通走 CTG GIA、移动走 CMI，回程三网统一收拢到 CMI，出口经 DMIT 自己的骨干网 AS906。洛杉矶 EB 则是回程按运营商分流：联通走 9929，移动走 CMIN2。

这样设计的结果是：移动用户用 EB 走的是移动自己的路，用 Pro 反而是借电信的 CN2 GIA 绕回来。联通用户在 EB 上走 9929，同样是本网最优。电信用户在 EB 上走 9929 或 CMIN2 的负载均衡，能用，但 9929 容量有限，高峰期偶尔会抖。

## Pro 与 EB 怎么选

**电信用户**：优先 Pro。洛杉矶 EB 的电信回程走 9929 / CMIN2 负载均衡，9929 容量比 CN2 GIA 小，高峰期有抖动记录。你要的是晚高峰不丢包，这个差价该花。东京场景同理，电信走 CMI 回程在 58–80ms，Pro 的 CN2 GIA 更稳。

**联通用户**：EB 更划算。9929 本来就是联通精品线，跨运营商损耗比电信用户用同一条线小得多。洛杉矶 EB 和 Pro 同价，等于同样的钱拿到本网最优线路。

**移动用户**：EB 几乎是默认选项。洛杉矶走 CMIN2，东京走 CMI，都是移动自家最好的国际出口。第三方测评记录东京到北京移动延迟 55–65ms，晚高峰表现稳定。

**三网混合的环境**（公司内网、访客来源杂）：EB 更均衡，不会因为某一条线路出问题全面崩掉。

**要 2Gbps 以上带宽跑流量**：只有 EB 有。Pro 系列没有这个档位，这是产品定位差异，不是价格问题。

## 真实成本：洛杉矶同价、香港便宜、东京反而更贵

很多人默认 Pro 一定更贵，实际不是这样。洛杉矶同规格的 Pro 和 EB 月付价格是对齐的，TINY 档都是 $9.99 起，STARTER 档都是 $16.90（按早期版本口径）。在洛杉矶，你选 Pro 还是 EB 完全取决于宽带运营商，不存在"多花钱买更好"的说法。

香港反过来，EB 比 Pro 便宜一整截：HKG.EB.TINYv2 是 $29.90，HKG.Pro.TINY 是 $39.90，差 $10 一个月。流量配额还是 EB 更多，1TB 对 500G。香港这边选 EB 的经济账很清楚。

东京是最反直觉的一个：TYO.Pro.TINY 月付 $21.90，TYO.EB.TINY 月付 $25.9，**Pro 的入门价反而更低**。原因是两边的套餐设计思路不同，Pro 的 TINY 就是最小可用配置，EB 从 TINY 开始就配 1Gbps 带宽和大流量，卖的是吞吐不是低价。你要是只需要一个日本节点做普通建站或代理，Pro TINY 更便宜也更稳；你要是拿它跑流量，那 EB 的 $25.9 买的是 Pro 给不了的带宽。

续费方面可以放心，DMIT 的续费价格和首次购买一致，没有"首年低价、次年原价"这种套路。这一条对长期用的成本影响很大，很多主机商第二年会涨一倍。

## 这几种情况不适合 EB

**电信用户且对回程敏感**：选 Pro。多花的钱买的是晚高峰的稳定性，这个场景下 EB 省不下来。

**只要一个日本节点、预算有限**：选 TYO.Pro.TINY，$21.90 比 EB 的 $25.9 便宜，回程还是 CN2 GIA。如果你单纯想要便宜的日本机器，TYO.T1 年付 $36.9 起更省，代价是没有中国大陆方向优化。

**业务面向海外、不服务国内用户**：T1 系列。流量配额更大，起步价最低，回国优化对你是纯浪费。

**对延迟极其敏感的场景**（游戏服务器、实时音视频）：直接看 HKG.Pro。香港到国内 10–50ms，是三个机房里最低的，贵有贵的理由。
